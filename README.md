# Odin Weather App

After a year of learning HTML, CSS, and JavaScript at Malmö University, I've been working through the projects in [The Odin Project](https://www.theodinproject.com/) curriculum.

This is the twelfth project - a weather app built with HTML, CSS, and JavaScript, using webpack and the Visual Crossing Weather API to fetch and display forecasts with async/await.

Weather data provided by [Visual Crossing Weather](https://www.visualcrossing.com/).
